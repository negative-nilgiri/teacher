# Go to definition

When a code block calls a function that another block defines, the learner
can now hover the name to preview the definition, and Cmd/Ctrl+click it to
jump there (Back returns). Nothing needs to be authored: the compiler finds the
definitions a lesson shows, and the browser links the names that use them.

This lesson is built so you can try it: the later excerpts call helpers shown
in earlier ones. Hover `strip_word(` or `extent(` in them.
